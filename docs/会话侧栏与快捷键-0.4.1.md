# 会话侧栏、图形化快捷键与点击兼容 · 0.4.1

2026-11-02。用户反馈标签压缩终端面积、文本式按键配置难用、默认缺 Tab，以及 Claude Code 在 Termux 中可以点击、在 bakaSSH 中仍不可用。

## 会话切换

移除 0.4.0 常驻的 48dp 标签行，改为左侧覆盖式抽屉。左侧边缘向右滑或点顶栏会话按钮打开，选中会话后关闭；返回键和遮罩也能关闭。抽屉打开 / 关闭不调整终端行列或远端 PTY。

侧栏显示会话编号、名称、地址、连接状态和新输出标记。点按切换，长按或右侧更多菜单重命名 / 关闭；底部可新建连接、编辑快捷键。最近使用会话、后台连接和断线后画面仍由 SessionService / TerminalSession 保管。

参考 Termux 的 [覆盖式布局](https://github.com/termux/termux-app/blob/master/app/src/main/res/layout/activity_termux.xml) 与 [会话选择逻辑](https://github.com/termux/termux-app/blob/master/app/src/main/java/com/termux/app/terminal/TermuxSessionsListViewController.java)。

## 快捷键配置

主页、设置、终端侧栏及更多菜单使用同一个图形化编辑页：

- 点布局中的键，再点下方键盘面板替换；选中项高亮。
- 长按拖动排序，或用左 / 右 / 上 / 下按钮调整位置。
- 每行可增删按键，整行可新增、删除、上下移动；新建布局最多 4 行，每行最多 10 个键。
- 支持自定义文字和符号，逗号与竖线也能独立使用。
- 保存后生效；返回时检查草稿，放弃后保留已保存布局。

新的两行默认键为：

| 第一行 | | | | |
| --- | --- | --- | --- | --- |
| Esc | Tab | Ctrl | Alt | ↑ |
| Home | End | ← | ↓ | → |

旧默认值自动映射到新默认，原有自定义配置继续读取；保存改用 JSON 行 / 键数组，旧文本配置保留为迁移备份。此前较宽的自定义行仍可读取，新添加操作遵守编辑器上限。退格、Shift、Enter、粘贴等可从面板自行添加。

快捷键通过 libvterm 编码，遵循远端 application cursor 模式与修饰键。Shift+Tab、Ctrl+方向键会发送相应组合；普通按键不再强制弹出软键盘。键盘按钮仍可单独控制输入法。

## 点击兼容修正

对照 [Termux 点击处理](https://github.com/termux/termux-app/blob/master/terminal-view/src/main/java/com/termux/view/TerminalView.java) 和 [鼠标模式状态](https://github.com/termux/termux-app/blob/master/terminal-emulator/src/main/java/com/termux/terminal/TerminalEmulator.java)，确认并修正三处差异：

1. 手指点击在抬起时，按抬起位置发送按下 / 抬起。旧实现使用最初按下位置，在小字号下微小偏移就可能点中邻格。
2. 手指点击和滚轮只设置坐标，不额外合成鼠标移动。旧实现通过 `vterm_mouse_move` 定位，1003 全跟踪模式会先产生 35 号悬停事件。本机 Claude Code 2.1.316 的完整启用组合包含 1000、1002、1003、1006；新增回归使用这个组合，旧代码确实失败，修正后通过。
3. 单独保存 1000 / 1002 / 1003 开关；关闭移动 / 拖动模式后，仍开启的点击模式继续工作，模式查询保持一致。硬复位也同步清理桥接层状态。

外接鼠标的真实按下、拖动、抬起和移动单独处理；取消、失焦、切换会话时释放按键。长按仍保留为本地文本选择，捏合与取消不转成点击。
