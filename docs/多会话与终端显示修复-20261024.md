# 多会话、后台服务与终端显示修复

2026-10-24，版本 0.3.0 / versionCode 9；保留原包名与签名，可覆盖升级 0.2.0。
本版发布为 GitHub Release；尚未完成本轮 Android 真机验收。

## 字形与光标

用户补充：Codex TUI 正常滚动时出现，不依赖缩放或切换页面。
沿此路径在真实 JNI / libvterm 中复现：写入“中”，回到同一位置只写 `i`，
旧实现留下全宽字符的尾随占位，把 `i`（U+0069）返回成 `width=2`。
旧渲染器据此选择 CJK 字体并横向拉成两格，符合英文被拉长的现象。
另两项“覆盖中文右半格”和“全宽字错位覆盖后滚动”也在旧代码失败。
本次在 libvterm 写字时清除被覆盖宽字的另一半，并将额外变化纳入 damage；
新的尾随格同时复制当前样式，避免继承旧背景。
修补后三项回归通过，其中重叠覆盖持续滚动 200 帧。

旧渲染器把每个字形都横向缩放成单元格宽度。遇到自然宽度较窄的字形或字体回退，
会放大字形；字形生成也依赖共享 Paint 上次留下的字号。
本次每次生成字形明确恢复字号、字体、粗体和斜体，只有超过单元格才横向缩小，
不会拉宽较窄字形。保留原有字体与粗体选择。
缩放期间采用相同宽度规则；自然步进不足一格时分别按单元格定位，不让文字段累积偏移。

已复现底层缺陷，仍没有手机上 Codex 那一帧的原始输出，
不能断言用户现场所有变形均由此引起，也不能当成 Codex 真机滚动已验收。
组合字符 / 塑形等既有能力边界仍见后续计划。

光标由单格空心框改成白色实心块；文字用深色重绘以保持可读。
光标落在中文双宽字符时覆盖两格；即使远端定位到尾随格，也覆盖完整字符。
远端隐藏光标的请求仍生效。

## 多会话

- 工具栏左侧会话按钮或标题打开会话列表；显示编号、当前项和连接状态。
- “新建会话”返回主机页，点击主机创建新连接；同一主机支持多次独立连接。
- 主页“返回会话”恢复已有连接。系统返回键只退出终端界面，不断开 SSH。
- 每条会话独立保存 SSH、libvterm 网格、字号与最后画面；非当前会话继续解析数据并立即答复终端查询。
- “关闭当前会话”只关闭所选连接；断线 / exit 后保留最终画面及状态，供查看、复制、关闭。
- Activity 重建后按会话 ID 重新挂接；View 只释放自己的缓存，不销毁服务持有的终端。

写入、应答、PTY resize 在各会话的顺序 IO 队列处理，resize 合并为最新尺寸。
启动命令仍在连接后延迟 1.5 秒发送，每条新连接仅一次。
连接时的密码 / 私钥口令在界面询问后交给会话，服务不持有 Activity，切换时重置输入法组词与粘滞按键。

## 后台保活

SessionService 在有会话时运行前台服务和低优先级常驻通知。
不随 Activity 的销毁或最近任务移除主动断开；通知可返回终端、切换休眠锁或断开全部。
Android 14 使用 specialUse 服务类型并声明 SSH 交互用途，避免把长期交互连接当成限时数据同步任务。
首次连接询问 Android 13+ 通知权限；拒绝通知权限不阻止连接，设置中可以再次开启。

终端菜单及主页设置提供“后台保活”：

- CPU / Wi-Fi 休眠锁默认关闭，用户可按需开启；启用会增加耗电。
- 休眠锁只在有活动连接时持有；全部结束、关闭或服务销毁会释放，开关偏好会保存。
- 电池优化入口显示当前状态，可主动申请忽略；另提供通知设置和应用信息入口供调整厂商后台限制。
- SSH 每 30 秒发送 server-alive 探测，连续 3 次未得到响应后判定连接失效。

该方案采用与 Termux 相同类别的前台服务和可选休眠锁机制，未测得与 Termux 相等的抗杀效果。
Android / 厂商仍可能回收进程；强行停止、重启和进程被杀会丢失 TCP 连接与内存终端。
服务不伪装恢复已经丢失的连接，也不在后台重放密码和启动命令；用户需重新连接。
服务使用 START_NOT_STICKY，与本地参考 Termux 的返回策略一致。

依据：[前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types#special-use)、
[Doze 与电池优化](https://developer.android.com/training/monitoring-device-state/doze-standby)、
[通知权限](https://developer.android.com/develop/ui/views/notifications/notification-permission)。

- Debug / Release / AndroidTest 构建及 lintRelease 通过（0 错误，68 项非阻断警告）；详见交付目录的验证记录。
- 新增 Android 像素回归：Paint 状态隔离、实心 / 双宽 / 尾随格光标、会话切换与借用句柄。

本轮 ADB 没有设备。像素回归只编译，未运行；UI、密码提示、系统通知、锁屏、Doze、
最近任务移除和厂商长期后台存活均未在设备验证，不能把离线测试当成这些场景通过。

建议真机按以下顺序复测：打开 Codex 正常滚动，观察英文和中英文混排行；
再交替查看粗体 / 斜体文字并缩放；
在中文行移动光标；同一主机开两会话并交替输入 / 缩放 / 关闭；
返回主页、从通知恢复、划掉最近任务再恢复；开启休眠锁和电池豁免后锁屏观察连接。
