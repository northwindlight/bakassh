# 0.1.2：逐帧真实文字缩放

用户明确要求：捏合过程中逐帧调整真实文字，不使用画布位图缩放预览。

## 行为

- 每个绘制帧合并此前的捏合采样，设置该帧实际字号，并计算和同步 libvterm 行列数。
- 手势期间直接通过 Canvas 绘制文字，连续且样式、字宽一致的字符合成文字段。
  字符在标准字号下的自然步进会缓存，字号变化时不重复测量、不重建字形或行位图。
- 结束手势后只按最终字号重建一次行缓存，继续使用原来的日常滚动渲染路径。
- 保留浮点字号比例，预览与最终字号使用同一份参数；松手不会再取整到另一档字号。
- 远端窗口变化最多保留一个待执行写入任务，未发送的旧尺寸由最新尺寸替代。
- 抬起第一根手指不会提前提交；取消、窗口变化和失去焦点会取消当前缩放，恢复手势前比例。
- 禁用双击单指缩放及手写笔缩放。FONT+/FONT- 使用每次 10% 的比例调整。
- 字号比例只在完整手势结束后持久化；旧的整数列数设置仍可读取，手动改列数会覆盖缩放偏好。

## 验证

新增主机侧回归覆盖浮点字号、松手不跳变、帧间采样合并、缩放边界反向响应、指针对重新开始、
取消恢复、1143 组网格尺寸、并发 resize 合并，以及 300 帧真实 JNI 终端 resize。
这些测试验证缩放状态、尺寸及 native 接线，不测量 Android 绘制帧率。

另附 `ZoomInstrumentation`：在 Android 的真实 View、Canvas、字体和双指 MotionEvent 上验证
松手前字号/网格已改变、手势期间未重建位图字形、松手不跳变、无鼠标或点击泄漏、取消及视口变化。
当前未连接 Android 设备，仪器测试只编译，不宣称已运行或达到指定帧率。
运行说明见 `tests/host/README.md`。
