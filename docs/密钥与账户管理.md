# 密钥与账户管理

依据后续计划落地多密钥管理、私钥导入及主机独立认证绑定能力。

## 能力范围

1. **多密钥对生成与存储**
   - 支持生成 RSA（2048 / 3072 / 4096）与 ECDSA（256 / 384）多种算法及规格，支持设置私钥保护口令与公钥注释。
   - 密钥存储于应用私有目录 `files/keys/`，元数据及指纹记录于 SharedPreferences，零额外数据库依赖。
   - 自动检测并平滑迁移原有单默认密钥 `sshterm_id_rsa` / `sshterm_id_rsa.pub`，保持向前兼容。

2. **外部私钥导入**
   - 支持直接粘贴导入 OpenSSH、PEM、PKCS#8 等格式的已有私钥（包括 ED25519、RSA、ECDSA 等）。
   - 导入时自动使用 JSch 检验密钥格式，支持输入解密口令验证；校验通过后自动提取公钥与指纹入库。

3. **密钥管理界面**
   - 主界面底部导航增加「密钥管理」入口。
   - 支持查看所有密钥列表（名称、算法类型、指纹、是否为全局默认、是否口令加密）。
   - 点击单个密钥支持：查看并一键复制公钥文本、设为全局默认密钥、重命名、删除密钥。
   - 删除密钥时自动检查并提示受影响的主机数量，确认后将关联主机自动回退到默认密钥。

4. **主机独立认证与密钥绑定**
   - 新建/编辑主机支持选择「公钥认证」或「密码认证」。
   - 公钥认证下可指定绑定特定密钥或跟随全局默认密钥；主机列表副标题直观展示绑定的密钥名称。
   - 密码认证下支持保存密码，亦可留空在每次连接时动态弹出输入框。
   - 私钥口令加密时，连接前在 UI 线程安全请求解锁口令并透传至 JSch。

## 验证

- **Host 单元与回归**：`bash tests/host/run.sh`（19 项）及 `tests/host/transport.sh`（4 项）全部通过。
- **Android Instrumentation**：`ZoomInstrumentation` 补齐密钥列表初始状态、密钥生成、默认切换、主机 JSON 序列化/反序列化及密钥删除回归，`assembleDebugAndroidTest` 编译通过。
- **Lint 与构建**：`gradle assembleDebug assembleDebugAndroidTest lintDebug` 均一次构建成功，无代码错误。
