# 方向键长按连发 · 0.4.3

2026-11-09，先执行 `git pull --ff-only`，确认基于远端最新的 0.4.2 / eb121f0 开发。

终端快捷键栏的 ↑、↓、←、→ 按下立即发送一次，持续按住后连续触发。首次等待和重复间隔使用 Android 的
[按键重复配置](https://developer.android.com/reference/android/view/ViewConfiguration#getKeyRepeatTimeout())。
松开不再额外发送一次；滑出按键后停止，滑回也不会重新启动，需要再次按下。

取消手势、失焦、隐藏 / 禁用按键、退出界面、打开会话侧栏、重建快捷键布局和切换会话均取消待执行的连发。
通过现有按键编码与发送队列发送，保留远端 application cursor 模式。其他快捷键保持单次点击。
