# bakaSSH 0.1.1 修复记录

显示名由 bakassh 改为 bakaSSH，包名仍为 `dev.northwind.bakassh`。

## 终端自动出现 libvterm(0.3)

该字符串来自 XTVERSION 查询的 DCS 应答。旧代码只在按键或鼠标输入时排空终端输出，
导致应答可能在查询程序超时退出后才送达 shell。
现在每次收到 SSH 字节都立即解析并把应答加入写入队列，优先于后续用户输入。
应答缓冲支持突发数据和分段读取，不再静默丢失尾部。

## TUI 局部滚动留下错行，缩放后恢复

旧代码将行位图搬到目标位置，但未同步搬运帧间已积累的脏行标记，
因此部分被修改过的源行在目标位置仍被认为缓存有效。
现在脏标记随整行搬运；局部列搬运标记目标行重画；事件队列或接收容量不足时明确重建整帧。
resize 会丢弃旧几何下的搬运事件，JNI 操作和绘制帧同步访问 libvterm。
纯黑背景色也会正确覆盖原背景。

## 本地选择复制与 tmux 冲突

- 长按选择单词，两个把手调整连续文本范围，跨行不再做矩形截取。
- 使用系统浮动操作条，不占终端高度，不因打开复制菜单而触发 PTY resize。
- 选择时冻结显示快照，复制读取同一份不可变文本；远端仍继续接收和解析，结束选择后显示最新内容。
- 确认滚动后取消长按；选择、捏合、取消手势不再产生远端滚轮事件。
- 复制日志只记录字符数量，不记录复制正文。

## 相关缺陷

切后台不再直接销毁 SSH 连接和写入线程，退出终端时统一释放；取消连接后拒绝重新连接，
EOF 时关闭 SSH 资源。输入法组词留在本地，只发送提交内容，组词中的退格不再删除远端文字。
去掉每次进入终端重复安装、持有旧 Activity 的全局异常处理器。

## 验证与范围

主机侧 12 项回归通过，其中包含 200 帧固定首尾 TUI 和 1000 帧混合 TUI 更新，逐行比较缓存与
libvterm 实际内容；另有 4 项 loopback SSH 协议回归通过，验证无需用户按键即可完成版本查询。
Android APK 构建和 lint 通过。测试命令见 `tests/host/README.md`。

当前未连接 Android 设备，因此未声称完成真机触摸、浮动菜单外观或各厂商输入法验收。
后台保留原 Activity 会话，不提供跨进程或系统强制回收后的会话恢复。
