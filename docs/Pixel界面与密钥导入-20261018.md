# Pixel 界面与密钥导入

2026-10-18，v0.2.0。

## 页面结构

用户明确以 Pixel 原生应用为视觉方向，ConnectBot 仅参考密钥导入交互。

- 首页保留简洁顶栏，大标题和两张柔和色块入口随主机列表滚动；主机使用两行圆角表面，添加按钮位于右下角。
- 主机编辑、密钥管理、生成 / 导入 / 详情、设置和扩展按键均为全屏页面，统一返回及顶栏主操作。
- 长表单使用可滚动内容和分区标题，标签与说明分离；返回时检查未保存的输入。
- 主机与密钥列表在行尾展开原生菜单；点击密钥进入详情，不再先弹操作列表。
- 主界面和编辑页沿用系统深浅色及动态取色；终端保留独立深色主题。输入框、按钮和图标使用 Material 组件与主题属性。
- 终端键盘按钮支持显示 / 收起；更多菜单可隐藏 / 显示扩展按键、确认断开连接。保留真实文字缩放、选择和渲染实现。

## 私钥导入

1. 密钥页点「导入」，通过系统文件选择器读取文件，不需要存储权限；也保留文本粘贴入口。
2. 文件读取、格式检查与后续解密 / 保存均在工作线程进行。文件名自动填入名称，并显示类型与加密状态。
3. 文件输入仅对加密私钥显示口令框；原始口令不去除首尾空格。失败保留页面与输入供重试，提交时阻止重复操作。
4. 自动处理 UTF-8 BOM / CRLF；误选公钥、空文件、超出 1 MiB、格式损坏及解密失败有明确提示。
5. 校验后派生公钥、保存原密文和加密标志；连接时仍需要解锁口令，不将导入私钥改存明文。

补齐 JSch 在 Android 使用的 Bouncy Castle 依赖；此前仅有 eddsa-java 无法满足其 BC 签名 / 密钥派生路径。

## 相关行为修正

- 打开密钥列表不自动生成 RSA；新安装可保持空列表，首个明确创建的密钥成为默认。
- 支持删除最后一个密钥；没有可用身份时连接给出返回提示。显式绑定丢失的密钥不静默替换成其他身份。
- 主机编辑提供独立的「跟随默认密钥」选项，并校验用户名、端口；终端设置校验边距和列数。
- 「恢复默认扩展按键」只修改编辑内容，点击保存后才生效。
- 旧私钥缺少 .pub 时尝试派生公钥，不重新生成或覆盖私钥；保留加密标志。
- Android 密钥测试改为独立目录和首选项，避免测试改变真实默认身份。
