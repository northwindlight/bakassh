# bakaSSH 0.4.6（预发布）：连接状态与一键重连、壁纸取色、启动图标与关于页
bakaSSH 0.4.6 打磨界面与日常体验：断线后可在终端里原位重新连接，终端外围跟随壁纸取色，补上启动图标，并新增关于页。本版同时包含 0.4.3–0.4.5 的方向键长按连发、UTF-8 分包修复与主机指纹信任 / 保存密码加密。

> 预发布版本，签名与此前发布包一致，可直接覆盖安装。真机验收后再转为正式版。

### 终端

- 连接中、失败、断开时在终端底部显示状态卡片：可取消连接、查看失败原因，断开后保留最后画面并可一键**重新连接**。卡片覆盖在终端上，不改变行列和远端 PTY，可收起。
- 重新连接沿用同一主机的最新配置与保存密码，新会话接替原会话在侧栏中的位置、名称和缩放。
- 顶栏状态点：已连接绿、连接中琥珀、失败红、已结束灰；侧栏会话卡片同色，后台新输出会在状态行提示。
- Ctrl / Alt / Shift 激活时改为主色填充，不再追加“★”，按键宽度保持不变。

### 取色与外观

- 终端工具栏、扩展按键、会话侧栏和弹窗跟随壁纸的深色方案；终端画面与配色保持固定。
- 主页加大强调色：运行中会话入口、首字头像、密钥 / 快捷键色块随壁纸变化。
- 新增自适应启动图标与 Android 13+ 主题图标单色层（此前未设置图标）。

### 主页、表单与关于

- 有会话时首屏显示“N 个会话正在运行”，已断开的会话单独计数；主机卡片显示运行中的会话数。
- 添加按钮滚动时收起；地址与端口同一行；校验错误显示在输入框下方。
- 设置分为显示 / 终端 / 关于；新增关于页，链接到 [作者 GitHub](https://github.com/northwindlight)、源代码、版本发布与开源许可。
- 指纹、地址、启动命令等使用等宽字体；密钥卡片显示“默认”“已加密”标签。

### 修复

- 主机指纹记录严格校验 Base64：系统解码器会跳过非法字符，损坏记录此前会被当成另一把公钥（仍会阻止连接，但提示不准确）。

### 验证

- GitHub Actions：主机回归与固定回放、Release 构建与 lint（0 错误）、API 34 模拟器完整截图流程，以及仓库自带的 Android 回归（字形渲染、缩放、主机信任与 Keystore 存储）。
- 尚未在真机上验收；厂商系统的后台与取色表现以真机为准。
