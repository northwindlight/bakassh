# bakaSSH 0.4.7（预发布）：修复方块字符拼接缝
bakaSSH 0.4.7 修复方块元素（Claude Code 像素 logo、进度条、btop 图表等使用的 `▐▛█▜▌▄▀░▒▓` 一类字符）之间的 1px 暗缝，并包含 0.4.6 的全部界面改动。

> 预发布版本，签名与此前发布包一致，可直接覆盖安装。

### 修复

- 方块元素 U+2580–259F 改为按整数格子边界直接绘制，不再使用字体字形：字形墨迹等于小数步进，取整落位会漏出 1px 缝。
- 行背景先整行绘制再画前景，背景段使用整数边界并关闭抗锯齿：此前下一格的背景会盖住上一格前景的最后一列像素。
- 新增主机侧逐像素几何回归与设备侧严格像素回归；CI 截图核对 logo 区域半覆盖像素为 0。

### 其他

- 快捷键名统一首字母大写（Esc / Ctrl / Alt / Shift）。
- 连接正常时顶栏只显示地址并省略默认端口，不再被截断成 `n…site:22`。

0.4.6 的连接状态卡片与一键重连、终端外围壁纸取色、启动图标与关于页见 [0.4.6 预发布](https://github.com/northwindlight/bakassh/releases/tag/v0.4.6)。
详见 [方块元素拼缝 · 0.4.7](https://github.com/northwindlight/bakassh/blob/v0.4.7/docs/方块元素拼缝-0.4.7.md)。
