# bakaSSH 0.4.8（预发布）：端口转发
bakaSSH 0.4.8 加入标准 SSH 端口转发（-L / -R），转发连接由独立后台服务维持，可选开机后自动恢复。本版同时精简了全应用的提示文字，并修正 ColorOS 的后台权限引导。

> 预发布版本，签名与此前发布包一致，可直接覆盖安装。

### 端口转发

- 入口在主页「端口转发」，或主机菜单 →「端口转发」；主页入口显示当前状态。
- 状态卡显示 未开启 / 正在连接 / 转发中 / 连接断开 / 启动失败，失败时给出原因。
- 规则用表单或命令两种方式写，可随时切换：表单下方显示等价的 `ssh -N -L … -R …` 命令，可复制到电脑上用；命令模式支持 -N、-L、-R、-p、-l、-g 和保活选项。
- 每条规则一张卡片，标出 L / R、`监听 → 目标`，以及在哪一侧监听、谁能连；点卡片编辑，⋮ 菜单排序或删除，删除可撤销。
- 认证复用已保存主机的密码或密钥，首次连接同样要核对主机指纹。
- 网络断开后自动重连；认证失败、指纹变化、端口被占用等需要手动处理。
- 未启动的修改自动保存为草稿；运行中改了规则，底部出现「应用修改」。

### 其他

- 精简全应用的提示和对话框文字，去掉重复说明。
- 后台常驻：ColorOS 直接引导到「耗电管理」，提示选择「完全允许后台行为」。
- 主机菜单把「删除」放到最后。

### 验证

- 主机回归：命令解析、IPv6、表单 / 命令往返、非法参数，以及真实 SSH 上 -L / -R 的双向传输、端口释放和部分失败回滚。
- CI 模拟器（API 34）：在转发页添加 -L 和 -R 规则并启动，从手机和 CI 宿主机分别连入，均收到 sshd 横幅；浅色 / 深色截图见 `ci-results` 分支。
- 转发功能曾在 OPPO PLB110 / Android 17 真机实测（-L 到远端服务器和本机虚拟机、覆盖更新后恢复）；新版界面尚未在真机上验收，整机重启后的自动恢复也还没测。

详见 [SSH 转发与后台权限 · 0.4.8](https://github.com/northwindlight/bakassh/blob/v0.4.8/docs/SSH转发与后台权限-0.4.8.md)。
