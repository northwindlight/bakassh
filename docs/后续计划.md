# 后续计划

2026-10-16 整理的后续范围；下列项目尚未完成。

## 性能与验收

- 根据[真机滚动实测](滚动性能实测-20261016.md)，优先定位大网格下文字栅格化与行缓存重绘成本，降低帧间波动。
- 增加相同网格、固定内容回放的基准，区分终端处理、网络输出与渲染成本；现场 TUI 对照保留为使用体验参考。
- 延长连续滚动与缩放后滚动测试，补齐 TUI 固定区域、鼠标模式和本地选区的真机验收。

## 下一阶段

- 密钥与账户管理：已实现多密钥生成/导入、管理界面与主机绑定，见[密钥与账户管理](密钥与账户管理.md)。
