- UI 整体重做：主机列表、终端操作和设置界面需要统一设计，现有界面不能作为最终方案。
- 密钥与账户管理：替代当前单一本机生成密钥和简单主机字段的管理方式。
- 多会话管理：同时保留多个连接，明确展示当前会话和连接状态，并能切换、关闭。
- SCP 文件传输。
- TUI 屏幕点击：正确转发应用启用的鼠标点击，协调点击、滚动、长按本地选择与键盘操作。

具体交互、数据结构及实现顺序在进入下一阶段时再定。
