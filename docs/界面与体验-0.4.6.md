# 界面与体验打磨 · 0.4.6

2026-11-19。用户反馈：整体体验不尽人意、手机上壁纸取色似乎没有生效，希望前端“有特色、好用”，并增加指向作者 GitHub 的关于页。
versionCode 16，沿用既有包名和签名。

## 连接状态与重新连接

此前连接中、失败和断开只显示在顶栏 10sp 的状态行里，断开后只能返回主页重新点主机。

- 终端底部覆盖显示状态卡片：连接中显示进度和地址，可取消；失败显示原因；断开 / 结束提示“已保留最后画面”。
  卡片覆盖在终端上，不改变终端行列和远端 PTY，可收起，状态变化后重新出现。
- “重新连接”使用同一主机：优先读取已保存主机的最新配置与保存密码；主机已删除时沿用会话里的连接参数，
  需要时询问密码或私钥口令。新会话接替旧会话在侧栏中的位置、名称和缩放，旧会话随后关闭；
  取消认证则保留旧会话和最后画面。更多菜单在会话结束后也提供“重新连接”。
- 顶栏状态行加状态点：已连接绿色、连接中琥珀色、失败红色、已结束灰色；会话卡片使用同一套颜色。

## 壁纸取色

- 主页仍按系统深浅色叠加 Material 动态配色，调用时机改到 `super.onCreate()` 之前，与库自带的
  `applyToActivitiesIfAvailable` 一致。
- 终端页原本完全不参与取色。现在工具栏图标、扩展按键、会话侧栏和弹窗使用壁纸的**深色**方案，
  终端画面、终端底色和 WT 配色保持固定。
- 主页加大强调色占比：运行中会话入口用主色容器，密钥 / 快捷键入口分用次色与第三色容器，
  主机首字头像在三种容器色之间轮换。取色生效时主页会明显随壁纸变化；系统本身不提供壁纸调色板时仍为默认蓝色。
- 新增自适应启动图标（此前清单未设置图标，桌面显示系统默认图标），并提供 Android 13+ 主题图标单色层。
  图标只用提示符与光标，不含名称，便于以后改名。

## 主页与会话

- 有会话时，大标题下方首先显示“N 个会话正在运行”，点按打开会话面板；主机卡片显示“N 个会话运行中”。
- 主机卡片改为首字头像；地址为默认 22 端口时省略端口。添加按钮向下滚动时收起为圆形，回到顶部再展开。
- 密钥 / 快捷键入口压缩为两张 72dp 的横向色块，把屏幕留给主机列表。
- 终端侧栏与主页会话面板共用同一种卡片：编号、名称、等宽地址和带状态点的状态行；后台有新输出时状态行提示并改用主色。
  主页会话面板不再使用旧式列表选择背景，并按会话数量调整高度。
- 粘滞修饰键激活时用主色填充，不再在键名后追加“★”，按键宽度保持不变。
- 终端更多菜单按使用频率重新排序，并修正重复的排序值。

## 表单、设置与关于

- 主机编辑页地址与端口同一行；启动命令使用等宽字体并关闭输入建议。
- 校验错误显示在输入框下方（Material 内联错误），修改内容后自动清除，取代旧式浮动错误提示。
- 设置页分为“显示 / 终端 / 关于”三组；“下次打开终端时生效”移到显示设置下方，后台常驻改为与快捷键一致的设置行，
  前台服务运行时显示会话数。
- 新增关于页：图标、版本号，以及作者 GitHub（github.com/northwindlight）、源代码、版本发布和开源许可链接；
  没有可用浏览器时复制链接。
- 密钥卡片指纹使用等宽字体，并以标签显示“默认”“已加密”；空列表改为带图标的说明。
- 首次连接 / 指纹变化弹窗中的指纹改为等宽粗体，便于逐段核对。

## 构建与 CI

树莓派 3（约 900 MiB 内存）无法完成 Android 构建，ECS 只有 2 核 3 GiB 且未安装 SDK，本版改用 GitHub Actions：

- 每次推送：主机回归与固定回放、`assembleRelease` + `lintRelease`、带 x86_64 的调试包与 AndroidTest 包；
  API 34 模拟器连接 CI 主机上的临时 sshd，走完主页、编辑、设置、关于、密钥、指纹确认、终端、侧栏、断开、重连、
  深色模式和更换系统取色种子的截图流程，并运行仓库自带的 Android 回归（`ZoomInstrumentation` 默认与 `security` 模式）。
- 日志与截图强制推送到 `ci-results` 分支，不登录也能查看。
- 推送 `v*` 标签：用仓库 secret `DEBUG_KEYSTORE_BASE64` 签名，核对签名证书与上一版发布包一致后发布 prerelease，
  证书不一致即拒绝发布。
- `-PemulatorAbi` 仅供 CI 模拟器额外打包 x86_64；发布包仍只含 arm64-v8a。

## 首次在设备上运行的 Android 回归

仓库自带的 Android 回归此前只编译、从未在设备上运行。本版在 CI 模拟器上首次运行，暴露并修正四处问题：

- **主机指纹存储**：`android.util.Base64` 会跳过非字母表字符而不报错，损坏记录被解码成另一把公钥，
  连接被当作“指纹变化”拦截（仍安全，但提示不准确）。现先严格校验格式，损坏记录按原设计报告“记录损坏”。
- **方向键连发**：`onVisibilityChanged` 只在附着窗口时分发，直接隐藏按键时连发不会停止；补 `setVisibility` 处理。
- **字形状态回归**：原测试用亮暗两种颜色比较 alpha，而 Skia 按颜色亮度调整文字 gamma，覆盖率本来就不同；
  改为同色、清缓存后重绘，仍检查 Paint 残留状态的影响。
- **终端高度回归**：断言漏减扩展按键栏上下留白（空栏也有 6dp）；改为排除按键栏后比较。

后两项是测试本身的问题，不是产品行为变化；修正后断言意图不变。

## 验证

- GitHub Actions（`ubuntu-24.04`）：72 项主机回归与固定回放通过；`assembleRelease` 与 `lintRelease` 通过，lint 0 错误、91 条警告。
- API 34 x86_64 模拟器（Pixel 6 配置）：连接 CI 主机上的真实 OpenSSH，完成 24 张截图流程：空主页、表单内联错误、
  添加主机、设置、关于、密钥生成与详情、首次指纹确认、终端、Ctrl 激活、侧栏、强制断开后的状态卡片、
  原位重连（新登录记录、名称位置不变）、主页运行标记、深色模式与更换系统取色种子后的主页 / 终端侧栏。
- `ZoomInstrumentation` 默认模式（真实字体渲染、逐帧网格、指针切换、字形状态隔离、CJK 光标、会话句柄、
  方向键连发、快捷键 JSON 与侧栏几何）与 `security` 模式（Android Keystore、密码迁移 / 恢复、主机指纹持久化）均通过。
- 模拟器不等于真机：OPPO / ColorOS 上的壁纸取色、后台保活、手势与输入法表现仍需真机验收。
