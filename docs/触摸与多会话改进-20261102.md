# 触摸与多会话改进 · 0.4.0 开发版

用户反馈：多窗口操作繁琐、点击无效、非 tmux 滚动有时没有反应，日常交互不足。
本次以终端触摸、历史记录和会话管理为范围；提供同包名、同签名的预览安装包，未发布 GitHub Release。

## 已查明的原因

旧版轻点只调用弹出输入法，未发送任何远端点击。滑动始终调用鼠标滚轮，但 libvterm 在远端没有开启鼠标上报时会直接丢弃；JNI 的历史行回调也只返回成功，没有保存文字。因此普通 shell 没有可用的本地回滚。

会话切换原本依赖弹窗和返回主机页，没有直接可见的标签、后台输出提示和重命名入口。取消新连接的认证会结束当前终端界面；通知总是指向最后创建的会话。

## 操作与行为

| 场景 | 当前行为 |
| --- | --- |
| 普通 shell 拖动 | 查看本地历史，支持惯性、滚动条；不向 shell 注入按键 |
| 备用屏幕，无鼠标上报 | 发送上 / 下方向键，遵循 application cursor 模式，例如 less |
| 远端开启鼠标上报 | 拖动发送滚轮；事件坐标保持在手势起点，避免跨过 tmux 窗格后转到其他窗格 |
| 轻点支持鼠标的 TUI | 在触点行列发送左键按下 / 抬起，不额外弹输入法；键盘按钮仍可单独开关 |
| 轻点普通 shell | 弹出输入法 |
| 长按 / 拖选 | 本地连续文本选择与冻结快照，包含当前可见的历史文字 |
| 捏合 / 取消手势 | 保持真实文字缩放；不产生额外点击 |
| 外接滚轮 | 使用相同的模式分流 |

点击能力取决于远端程序是否开启鼠标上报；单纯显示出来的文字不会自动变成按钮。tmux 也需要启用自己的鼠标配置。

历史归独立终端会话所有，最多 4096 行，并限制为 16 MiB 的历史行分配；另有屏幕和绘制缓存的内存。达到任一上限时丢弃最旧行。阅读旧输出时，新输出保持阅读位置；被上限淘汰的内容无法保留。点击浮动“回到底部”或输入文字恢复跟随输出。断开连接后，本地历史仍可滚动。

当前保存物理行及其原始宽度，历史在新列宽下截断显示或补空；没有实现历史全文随字号重新排版。备用屏幕内容不混入普通 shell 历史。

终端顶端常驻横向会话标签，可点按切换、点关闭图标关闭、长按管理；正在连接、失败、结束以及后台新输出有可见提示。会话总览可查看地址 / 状态、切换、重命名和关闭，主页共用同一入口。重命名仅作用于当前会话，不改保存的主机名称。

右侧加号直接选择已有主机建立独立连接。取消认证保留原会话，关闭当前标签后选取邻近标签；通知返回最近选择的会话。扩展按键的显示 / 隐藏会保留。

粘贴遵循远端协商的 bracketed paste 模式，开始标记、正文、结束标记使用同一顺序发送队列；统一换行为 CR，去除正文中的 ESC，防止粘贴内容提前结束标记。

## 验证

- `tests/host/run.sh`：32 项通过，其中 10 项为新增触摸协议 / 历史回归；使用真实 JNI 和 libvterm。
- `tests/host/transport.sh`：11 项通过。真实 loopback SSH 接收并核对点击按下 / 抬起、滚轮坐标 / 次数及带 CRLF / ESC 文本的粘贴字节顺序；覆盖多连接隔离和 EOF 后本地回滚。
- 新增 10 项历史 / 协议回归在 UndefinedBehaviorSanitizer 下再次通过。
- Debug、Release、Android instrumentation APK 构建通过；`lintRelease` 无错误，既有及新增提示见构建报告。
- Android 新增 MotionEvent + JNI + Canvas 回归：shell 轻点、TUI 点击、滚动起点、取消手势、历史画面变化与回到底部恢复。**本轮无 ADB 设备，只编译，未执行。**

尚需真机验收：不同 DPI 与键盘下的标签操作、Bottom Sheet、长按菜单、真实 TUI 点击位置、持续输出时的惯性手感，以及系统 / 厂商后台行为。本次不宣称已达到 JuiceSSH / Termux 的完整交互能力，也未重新测量滚动性能。

模式分流参考 [Termux 官方 TerminalView](https://github.com/termux/termux-app/blob/master/terminal-view/src/main/java/com/termux/view/TerminalView.java) 的鼠标 / 备用屏幕 / 本地历史三条路径；本项目实现继续基于现有 libvterm 和行缓存。
